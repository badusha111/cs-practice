# Практическое занятие 08 — NumPy

Файл с решением: `lab08_numpy.py`.

В работе рассматриваются:
- создание одномерных и двумерных массивов;
- индексация и обычные срезы;
- получение строк, столбцов и прямоугольных фрагментов;
- изменение элементов срезами и копирование через `.copy()`;
- изменение формы массива с помощью `.reshape()` и транспонирование через `.T`.

## Запуск

Установите NumPy, если он ещё не установлен:

```bash
python -m pip install numpy
```

Запустите решение из корня репозитория:

```bash
python lab08/lab08_numpy.py
```
