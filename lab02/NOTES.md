Git - это система контроля версий, работающая локально, а GitHub - облачный сервис для хостинга проектовна основе Git.

коммит - это сохранение текущего состояния файлов в истории Git с уникальным номером и сообщением.

Использованные команды:
git status - показывает, какие файлы изменены, какие уже в индексе и что готово к комиту.
git diff  - сравнивает рабочую директорию с индексом. То есть показывает изменения, которые еще не добавлены через git add.
git diff --staged - сравнивает индекс c последним комитом. То есть показывает, что уже добавлено и попадет в следующий комит

Ветки: 
Ветка - это подвижный указатель на определенный комит, позволяющий вести паралельную разработку.

При новом комите указатель ветки автоматически сдвигается вперед на этот новый комит.

Слияние - переносит изменения из одной ветки в другую, создавая общий комит, где объединяются обе истории.
